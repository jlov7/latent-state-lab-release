# Contributing

Include a reproducing fixture, a focused regression, commands/results and remaining
limits. Preserve negative comparisons and frozen evidence. Run the README's pinned lint, core
and package verification commands, plus the numerical tests when changing the
optional probe. Do not add model weights, confidential logs, personal data,
credentials or material without redistribution rights. Original code is MIT
licensed; separately installed dependencies retain their own terms.

Use the [stability policy](docs/STABILITY.md) for compatibility changes and
[release checks](docs/RELEASING.md) for package, documentation and example gates.
